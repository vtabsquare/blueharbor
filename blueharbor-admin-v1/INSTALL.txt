ADMIN LOGIN PATCH

1. Stop the admin app with Ctrl+C in its terminal.
2. Back up your existing backend/supabase_auth.py.
3. Copy the backend folder from this ZIP into:
   D:\Python\Project Blueharbor\blueharbor-admin-v1
4. Accept replacement of supabase_auth.py only. Do not delete the backend folder.
5. Run run_local.py again and refresh the browser.

Login no longer imposes a minimum or maximum password length.
The admin login form already has no minimum; its backend check is now removed.
Password is still required and must match Supabase Auth.
Creating staff accounts and changing passwords still require 12 characters.
No .env, credentials, database, inventory, users or admin permissions are modified.
The buyer application has a separate patch ZIP.
